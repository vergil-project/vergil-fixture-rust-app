## Features

- **add the Rust CLI program and run CodeQL on it (#4)**
* feat(fixture): a small CLI with greet, sum and info subcommands

The fixture's program: a clap CLI with three subcommands, one module each, unit and end-to-end tests at 100% line coverage, the docs pages and the README. Runtime dependencies: clap, anyhow and serde_json. Epic vergil-project/.github#1091, plan Task 6d.

* ci(security): run CodeQL on Rust so the required checks report

Remove run-codeql: false so the security job runs CodeQL on Rust. The CI-gates ruleset requires security / codeql and the GHAS CodeQL check, so every PR here was blocked with all checks green.

- **add the max subcommand (#8)**
max NUMBERS... prints the largest of its integers and fails when none are given. Its logic function carries a doctest, the first in the fixture, so the cargo test --doc step validates a real test. Ref vergil-project/vergil-fixture-rust-app#5
