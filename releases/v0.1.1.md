## Features

- **add the min subcommand (#24)**
* feat(cli): add the min subcommand

Prints the smallest of its integer arguments, and fails when given none, mirroring max. Tests cover the function, run (success, error and write error), parsing, dispatch and the binary end to end.

* chore(deps): roll anyhow back to 1.0.103 in Cargo.lock

## Testing

- **bring region coverage to 100% before the Rust region gate (#19)**
* test(coverage): cover every region

Region coverage was 98.64% (5 of 368 regions missed; lines 100%). Four were the write-error ? of each command's run, and one the unreachable false arm of an unguarded matches! in parses_info. llvm-cov counts a generic function's regions from its best-covered instantiation alone, so every run test now shares one writer type (a bounded byte slice, through commands::testing::capture), and a zero-capacity writer drives the write error. parses_info compares the Debug form instead. No exclusion is added.
